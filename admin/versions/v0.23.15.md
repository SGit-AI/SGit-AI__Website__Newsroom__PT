**The four department agents have English names.** `pesquisa.pt` is `research.pt` (@Research),
`redacao.pt` is `desk.pt` (@Desk), `verificacao.pt` is `verification.pt` (@Verification) and
`bastidores.pt` is `backstage.pt` (@Backstage). The id is a protocol address — it names the mail
folder and will be the address other sites' agents write to — and the alias is an operator handle.
Both are operations, and operations are English. The editor called `bastidores.pt` a mistake on
the day it was about to be baked into a signing key and published in a contact file other agents
would cache; that is the one moment a rename is cheap, so all four went together.

**Four things did not move, and the register says why** (`dados/agentes.json`,
`o_que_nao_mudou_na_renomeacao`). The display names — *Pesquisa*, *Redação*, *Verificação*,
*Bastidores* — are what a reader sees on the newsroom-floor page, in Portuguese: content. The
`id_curto` department keys are what gate 12 checks, and gate 12 is in deny-listed `build/gates.py`:
they move with the English migration (task #5), not before. The `@redacao.local` mail domain is in
every message already sent. And the bridge id `editor-para-bastidores` is the key under which the
editor's own browser stores the append credential; renaming it would silently lose that credential.

**Nothing that is a record was rewritten.** Twelve messages carry `From: bastidores.pt` in their
headers, and nine run records are signed `bastidores.pt`. Mail is never edited and a run record
says who ran. Each old id is now in `identidades_historicas` with `renomeada_para`: the mail
reader resolves an old address — and its alias — to the live agent on the way in, so one agent
does not appear under two names; gate 35 accepts a retired id on an old run record. It still fails
an agent nobody registered, and still fails the bootstrap session's id, which was retired without
a successor — both broken on purpose and both red. The mail folders moved with `git mv`, so the
box a message sits in was right before a line of code changed.

*Not done, and said: the mail README and this note both still spell the old ids, deliberately, as
history. The three translation files hold orphaned translations of one line that named
`pesquisa.pt`; the i18n gate reports them kept and none served, which is what a changed source is
supposed to produce.*
