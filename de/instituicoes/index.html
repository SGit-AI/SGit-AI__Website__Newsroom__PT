Institutionen

Öffentliche Stellen, Aufsichtsbehörden, Forschungseinheiten — und was sich aus dem Register, das sie veröffentlichen, lesen lässt oder nicht.

Was dieser Abschnitt heute behaupten kann

Dass drei Seiten des nationalen Registers an einem Datum abgerufen wurden, und wie viele sichtbare Zeichen jede einem automatischen Leser zurückgab.

Was es nicht kann

Dass eine Institution etwas verbirgt. Eine Seite, die per Skript rendert, ist eine gängige technische Wahl.

Die Lesbarkeit des öffentlichen Registers ist messbar, datierbar und hashbar. Die Absicht dessen, der es veröffentlicht, ist es nicht.

Editor (8)

Das Haus, das eine eingefrorene Seite veröffentlicht: eine öffentliche Stelle, eine Zeitung, ein Portal, die eigene Website einer Veranstaltung. Es geht aus dem Herausgeberfeld des Registers durch die Formel `editor_de_fonte` hervor und sagt, wer die Seite VERÖFFENTLICHT — nicht, wer sie schrieb, nicht, wer sie betreibt. Es existiert als eigener Typ, weil die Definition von Institution «um organismo público, um regulador ou uma unidade de investigação» ist, und eine Zeitung ist keines davon: jene Definition zu erweitern, damit sie hier passt, würde ändern, was sie verspricht.
