Comentários e decisões

Ainda não há comentários. Um comentário é um ficheiro em redacao/revisoes/: quem o escreveu, quando, sobre que item, e o texto. Fica no repositório como tudo o resto.

Como o editor de registo aprova ou rejeita

Uma decisão é um ficheiro, como tudo o resto nesta redação, e fica no repositório onde qualquer pessoa a pode ler. O editor escreve redacao/revisoes/chatgpt-2026-09-15-politicas-2.json — ou corre /newsroom-entregas, que percorre os itens um a um e escreve o ficheiro por ele. Um item sem entrada fica por rever, que é o estado seguro; só aprovada o deixa ser escrito como facto, e só uma pessoa o escreve.

{
  "entrega": "chatgpt-2026-09-15-politicas-2",
  "estado": "em_revisao",
  "decidido_por": "<o nome do editor>",
  "decidido_em": "<hoje>",
  "itens": {
    "item-pol-09": {
      "estado": "aprovada",
      "comentario": "1 de 2 afirmações com o excerto nos bytes"
    }
  },
  "comentarios": [
    {
      "quem": "<quem>",
      "quando": "<datahora>",
      "sobre": "item-pol-09",
      "texto": "<o comentário>"
    }
  ]
}

Uma regra que o portão impõe e não é uma preferência: não se aprova um item cujas afirmações estejam todas «sem fonte legível». Aprovar quer dizer «isto pode ser escrito como facto», e não há bytes para o sustentar. Se o item for valioso — e vários destes são — o caminho é abrir um issue de pesquisa para encontrar uma fonte que se consiga ler, e não baixar a barra.
