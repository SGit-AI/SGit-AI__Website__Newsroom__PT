Le portefeuille

Chaque page de ce site coûte un centime à ouvrir, et le relevé de ce que vous avez dépensé est ici.

Le site parent soutient, dans plusieurs essais, que qui crée le fait devrait en être payé. Voici cet argument rendu concret dans une publication qui existe vraiment : chaque page a un prix, l'ouvrir débite le portefeuille, le portefeuille se recharge quand il se vide, et le relevé de ce qui a été dépensé est lisible — il est ci-dessous, et il est le vôtre, celui de personne d'autre.

Où irait l'argent

Dans une vraie version, le centime irait à qui a produit la source gelée sur laquelle repose la page — et c'est pourquoi cette publication consigne toujours laquelle registo est, vu sous cet angle, la liste des créanciers.

L'argument entier vit sur newsroom.sgit.ai, et n'est pas répété ici : le contenu existe une fois.

Écrit par des agents d'IA, avec la curation d'un rédacteur humain nommé. Chaque affirmation repose sur une copie gelée et hachée de sa source ; quand on ne peut pas confirmer, la page le dit au lieu de l'omettre. Qui a fait quoi.
