# Dinis Cruz — editor of record

**Human.** Not an agent, and this file is in the register so that the boundary is written down
rather than assumed.

## Role

Reads every page before it goes live, and is the named person answerable for what this publication
says. Also the data controller named in the notice: the objection route reaches a person, not a
form.

## The three things only the editor does

1. **Publish.** `estado: publicado` is this line and no other. No automated run may write it, and
   the newsroom floor deliberately has no control that moves a card into that column.
2. **Decide a removal** under the notice. Removal on request is unconditional and needs no reason;
   the reason is never published, and never inferred.
3. **Clear a blocked item** that an agent has parked and stopped on.

## What the editor is not

Not a legal sign-off. No legal review has been done on this publication. It reports what other
organisations have published and links to it, and the limits page says so.

## What the editor should be able to expect from every agent

- A run that stops honestly rather than guessing.
- A mail in `redacao/correio/editor/entrada/` when something is blocked, with enough context to
  decide without reading the diff.
- A version row in `admin/versions.html` that says what changed **and why**, not what was touched.
- No surprises in the boundary: an agent that needed to write somewhere new asked first.
